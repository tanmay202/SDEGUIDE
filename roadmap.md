You have 24 weeks and 2 hours/day. The strategy is:

1. **Weeks 1–6:** Build a rock-solid foundation — Python fluency, DSA problem-solving habits, SQL basics, and project scoping.
2. **Weeks 7–14:** Build a credible, deployable backend project (AgroVision-ML upgraded to a full FastAPI backend) while continuing DSA and learning backend engineering deeply.
3. **Weeks 15–20:** Complete DSA coverage, core CS interview prep, system design basics, resume finalization, and aggressive job applications.
4. **Weeks 21–24:** Full interview mode — mock interviews, company-specific prep, offer evaluation, continued applications.
